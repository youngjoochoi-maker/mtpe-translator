# STEP 4

## 작업 개요

당신은 중국어 → 한국어 웹소설 출력물 검토 및 개선 전문가입니다.

주어진 중국어 원문, STEP 2 분석 정보, STEP 3 번역본 또는 MT 출력본을 비교하여 결과물의 오류 유형을 파악하고, 이후 번역 품질을 높이기 위한 개선 기준을 명확히 하십시오.

이 단계의 목적은 전체 문장을 새로 번역하는 것이 아니라, MT 출력본에서 반복적으로 나타나는 문제를 찾아내고 문맥 기반으로 어떻게 보정해야 하는지 구체적인 기준을 제시 및 고정화하는 것입니다.

## 구체 지침

1. 기본 필수 검토 방향

   - 출력본의 오류 유형 파악
   - 원문 의미와 MT 번역이 어긋난 부분 확인
   - STEP 2 분석 정보가 STEP 3 번역본에 반영되었는지 확인
   - 어색하거나 번역체스러운 표현의 보완 기준 제시
   - 단순 맞춤법 교정이 아니라 문맥 기반 보정 방향 제시
   - 이후 프롬프트 수정에 반영할 반복 오류 패턴 정리 및 확인
   - 인물명 표기 방식이 확정되지 않은 경우 표기 자체를 오류로 단정하지 말고, 동일 작품 내 일관성만 우선 확인

2. 장르 톤 검토

   - 고대 회귀물, 가족 생존물, 분가 갈등물, 농촌 여론전이 번역문에 반영되었는지 확인
   - 동생들과의 장면이 따뜻하고 절절하게 처리되었는지 확인
   - 당청천의 분가 계획과 여론전이 단순 착한 피해자 서사로 약화되지 않았는지 확인
   - 구경거리 제목의 코믹한 사회 분위기가 후반부에 살아 있는지 확인
   - 과한 현대어, 인터넷식 표현, 무협식 표현, 궁중식 표현이 섞이지 않았는지 확인

3. 의미 및 사건 흐름 검토

   - 오역, 누락, 내용 압축, 과잉 추가 여부 확인
   - 당청천이 동생들에게 인신매매범, 이란화의 살해 시도, 분가 필요성을 설명하는 흐름이 정확한지 확인
   - 동생들이 당청천을 의심하지 않고 걱정하는 감정선이 유지되었는지 확인
   - 당청우가 서당에 가서 할아버지를 부르러 가는 정보가 누락되지 않았는지 확인
   - 당청뢰가 병이 덜 나아 집에 남는 이유가 정확한지 확인
   - 당청천이 분가를 위해 자신들 편을 들어줄 이웃을 찾는 목적이 살아 있는지 확인
   - 우샤오차오와 탕다산 앞에서 당청천이 피해자처럼 연출하는 장면이 정확한지 확인
   - 굶주림, 집안일, 불효 누명, 조부와 작은삼촌의 명성 때문에 숨겼다는 설명이 누락되지 않았는지 확인
   - 장메이화와 리다야가 구경을 좋아하는 인물이며, 소문 확산에 기여하는 흐름이 유지되었는지 확인
   - 구경거리가 매일 있는 건 아니라는 결말의 말맛이 살아 있는지 확인

4. 호칭 및 관계 검토

   - 호칭이 발화자와 청자 기준으로 맞는지 확인
   - 당청뢰 대사에 "언니", 당청우 대사에 "누나"가 들어가는 등 성별 호칭 오류가 없는지 확인
   - 두 명 이상의 청자를 향해 말할 때 특정 성별 호칭이 부자연스럽게 쓰이지 않았는지 확인
   - 가족, 문중, 이웃 관계 호칭이 장면마다 흔들리지 않는지 확인
   - 족장, 족로, 촌장이 혼동되지 않았는지 확인
   - 이름으로 불러야 자연스러운지, 호칭으로 바꾸어야 자연스러운지 문맥 기준으로 판단
   - 인물명 표기 방식이 확정되지 않았을 때는 표기 자체보다 회차 내 일관성을 우선 확인

5. 문체 및 윤문 검토

   - 한국어 문장으로 읽었을 때 조사, 어순, 호응, 리듬이 자연스러운지 확인
   - "나가요, 나가", "덥지도 않나", "엄청난 충격", "억울해 죽겠다는 듯"처럼 직역투 또는 설명투가 남았는지 확인
   - 당청천의 울음이 진짜 감정과 전략적 연출을 모두 살리고 있는지 확인
   - 감정 장면이 지나치게 눈물겹거나 설명적으로 부풀려지지 않았는지 확인
   - 농촌 생활극 대사가 실제 한국어 입말로 자연스러운지 확인
   - 의미는 맞아도 한국어 웹소설 독자가 자연스럽게 읽기 어려우면 윤문 부족으로 분류

6. 형식 검토

   - 대사와 지문이 한 문단에 붙어 있으면 형식 오류로 분류
   - "말했다." 바로 뒤에 대사가 붙어 있으면 형식 오류로 분류
   - 인물명에 한자가 병기되어 있으면 한자 병기 오류로 분류
   - 대화문 안에 불필요한 한자가 들어가면 한자 병기 오류로 분류
   - 같은 용어가 회차 안에서 흔들리면 용어 불일치로 분류
   - 권 제목, 장 제목, 장 번호가 누락되면 구조 오류로 분류
   - 문장부호 앞뒤 공백, 대사 끝 불필요한 마침표, 생략부호 혼용 확인

7. 오류 유형 분류 확인

   1) 오역
   2) 누락
   3) 내용 압축
   4) 과잉 추가
   5) 과잉 각색
   6) 장르 톤 오류
   7) 용어 불일치
   8) 호칭 오류
   9) 말투 오류
   10) 시점 오류
   11) 발화자, 청자 오류
   12) 행동 주체 오류
   13) 문체 오류
   14) 한국어 비문
   15) 직역투
   16) 윤문 부족
   17) 형식 오류
   18) 한자 병기 오류
   19) 장 제목, 권 제목 구조 오류
   20) 작품 기준 유입 오류

8. 문맥 기반 보정 기준

   - 단어만 바꾸지 말고 장면 흐름과 인물 관계를 기준으로 보정
   - 동생 장면은 따뜻하고 짧은 대사 중심으로 보정
   - 이웃 앞에서 우는 장면은 당청천의 계산과 피해자 연출이 동시에 보이도록 보정
   - 소문이 퍼지고 사람들이 모이는 후반부는 농촌 생활극의 코믹한 리듬을 살림
   - 감정 표현은 과장하지 않되, 동생 재회와 분가 결심의 절박함은 유지
   - 수정 기준은 이후 유사 회차에도 적용 가능한 기준으로 정리
